# Spendly 💸

Spendly is a simple expense tracker I built to manage my income, track daily expenses and keep an eye on my savings goals.

### Features
- Add, edit and delete income and expenses.
- Search, filter and sort transactions.
- View monthly spending and category-wise breakdowns.
- Create and manage multiple savings goals.
- Track savings progress.
- Export and import financial data.
- Save data using localStorage.

### Tech Stack
- HTML
- CSS
- JavaScript
- localStorage

### Getting Started
Clone the repository and open `index.html` in your browser.
